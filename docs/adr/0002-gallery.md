# ADR 0002: gallery publications

Date: 2026-11-08. Status: gallery accepted for MVP; publication details proposed.

The founder requires opt-in sharing and discovery of journals about the same book. Private journaling remains the default. Proposed implementation: publish explicitly selected snapshots, never live private tables, with update/unpublish and basic reporting/removal. Group by work and preserve edition differences. Proposed initial audience is signed-in members; confirm before policy implementation. This adds publication revisions, catalog identity and moderation responsibilities to the MVP. Social engagement mechanics remain deferred.
